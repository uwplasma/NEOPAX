Tutorials
=========

The tutorial material currently lives mostly in example TOML files and worked
examples.

Start with:

- :doc:`worked_examples`
- :doc:`quickstart`
- :doc:`input_file_reference`

Recommended path
----------------

1. Run a small theta example.
2. Run a Radau example.
3. Inspect the output directory and generated HDF5 file.
4. Change a profile or solver tolerance through the TOML.
5. Move to NTX-backed examples once the basic solver workflow is clear.
