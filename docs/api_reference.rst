API Reference
=============

The generated API reference is provided by AutoAPI from the ``NEOPAX`` Python
package.

When building the documentation, the generated module pages are placed under
the AutoAPI output tree.  The most commonly used public entry points are:

- ``NEOPAX.load_config``
- ``NEOPAX.prepare_config``
- ``NEOPAX.run``
- ``NEOPAX.run_config``

For usage examples, see :doc:`methods_of_use`.
